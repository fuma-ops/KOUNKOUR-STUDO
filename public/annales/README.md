# Photos des sujets originaux (annales)

Un dossier par série : `public/annales/<slug-de-la-série>/p1.jpg`, `p2.jpg`…
(JPEG, largeur ≤ 1600 px, ≤ 400 Ko par page). Les chemins `/annales/<slug>/pN.jpg`
sont enregistrés dans `qcm_sets.source_images`, avec la page d'origine dans
`qcm_sets.source_url`. Les questions sont transcrites mot pour mot ; un corrigé
n'est publié que s'il est vérifié, sinon la question reste « a_verifier ».
